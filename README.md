# PenCom website and mobile app design: Option B

Design option B for the National Pension Commission (PenCom) website and mobile app.
All content shown is sample content for review.

## Run locally

```bash
npm install
npm run dev
```

Then open the address shown in the terminal.

## Pages

- Website: Home, About, Services, Operators, Resources, Regulations, Connect
- Mobile app preview: `#/mobile`
- CMS dashboard preview: `#/admin`

Photos in `public/d2` are free stock photos used for the demo only (see `public/d2/CREDITS.txt`).
